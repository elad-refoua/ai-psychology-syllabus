# שימוש בבינה מלאכותית בפסיכולוגיה — סילבוס

עמוד הסילבוס לקורס **״שימוש בבינה מלאכותית בפסיכולוגיה: יישומים מחקריים וקליניים״**
(Using Artificial Intelligence in Psychology: Research and Clinical Applications).

מרצה: אלעד רפואה · המחלקה לפסיכולוגיה · סמסטר ב׳ תשפ״ז · 2 נ״ז

## מה יש כאן

`index.html` — עמוד יחיד, עצמאי לחלוטין (ללא תלויות בנייה). כולל:

- 13 המפגשים בשלושה חלקים, עם ההתנסות המעשית של כל מפגש
- שלוש מסגרות הקורס: ״לחשוב עם מכונה״, SMART, CARE
- ביבליוגרפיה מקושרת ל-DOI, עם סימון פריטים בגישה חופשית
- משאבים מלווים: האתר הנלווה, הרצאות מוקלטות וכלים פתוחים
- סגנון הדפסה נפרד — הדפסה או שמירה כ-PDF מייצרת מסמך סילבוס רשמי ומסודר
- תמיכה במצב כהה ובמסכי טלפון

## הפעלה מקומית

פתיחת `index.html` בדפדפן. אין שלב בנייה.

## עדכון תוכן

כל התוכן נמצא ב-HTML עצמו. מפגש = בלוק `<article class="session">`;
פריט ביבליוגרפיה = `<li class="ref">` בתוך `<ol class="refs">`.
`.nojekyll` מונע מ-GitHub Pages לעבד את התיקייה דרך Jekyll.
